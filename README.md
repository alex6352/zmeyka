# Змейка на C++ — вариант «5 сундуков»

## Описание

Проект содержит консольную игру «Змейка» и графическую версию на SDL2 (если библиотека доступна в системе). Игровая логика исходного проекта сохранена: поле 10×10, стартовая длина 1, еда, пять сундуков, мигание и подсветка сундуков, рост, счёт, победа и проигрыш при столкновении.

## Структура

- `include/snake.h`, `include/snake_sdl.h` — публичные интерфейсы приложений.
- `src/snake.cpp` — консольная игровая логика и запуск.
- `src/snake_sdl.cpp` — графическая версия на SDL2.
- `src/main.cpp`, `src/main_sdl.cpp` — отдельные точки входа.
- `tests/` — команда запуска проверок.
- `.clang-format` — единый стиль форматирования.

## Сборка и запуск

Требуются CMake 3.16+ и компилятор C++17.

```sh
cmake -S . -B build
cmake --build build --parallel
./build/snake
```

Графическая версия собирается автоматически, если обнаружена SDL2. На Ubuntu/WSL её можно установить командой `sudo apt install libsdl2-dev`. После сборки запуск: `./build/snake_sdl`. В WSL для графического окна требуется поддержка WSLg или настроенный X-сервер.

## Управление

- `W`, `A`, `S`, `D` или стрелки — движение.
- `H` — справка.
- В консольной версии `Q` — выход.
- В SDL2-версии `P` — пауза, `R` — перезапуск, `Esc` — выход.

## Подзадачи и функции

Консольная версия содержит функции настройки и восстановления терминала (`setupTerminal`, `restoreTerminal`), вывода справки (`printHelp`), чтения клавиш (`readKey`), отрисовки поля (`drawField`), генерации еды (`spawnFood`), размещения сундуков (`placeChests`) и игрового цикла (`runGame`). В SDL2-версии класс `Game` хранит состояние и реализует шаг, поворот и сброс игры; функции отрисовки отвечают за визуальное представление.

## Обработка ошибок

Неизвестные клавиши игнорируются. Сборка SDL2 является необязательной: если SDL2 не найдена, CMake сообщает об этом и продолжает сборку консольной версии. Для системных ошибок создания SDL-окна/рендерера графическая версия завершает инициализацию с ненулевым кодом.

## Проверочные сценарии

CTest запускает встроенный автотест игрового алгоритма для нескольких начальных seed: `1`, `7` и `42`. Автотест моделирует управление ботом и проверяет возможность собрать все пять сундуков. Дополнительно вручную проверьте: запуск консольной версии; игнорирование неизвестной клавиши; вызов справки; движение к стене и проигрыш; паузу/перезапуск/выход в SDL2-версии.

```sh
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

## Пример

В консольной версии пустая клетка обозначается `.`, еда — `*`, голова змейки — `O`, тело — `o`, видимый сундук — `$`, подсвеченная клетка сундука — `#`. Обычная еда добавляет 1 очко и 1 сегмент; сундук добавляет 2 очка и 1 сегмент. Открытие всех пяти сундуков означает победу.
